# Талаа — дневник фермерского хозяйства

Интерактивный прототип мобильного приложения для фермера: поля и культуры, быстрые записи расходов и работ, история цен, аналитика по прибыли на гектар и прогноз урожая.

**Языки:** кыргызский, русский, английский. Язык выбирается при первом запуске и меняется кнопкой с глобусом в правом верхнем углу.

## Возможности

- Настройка хозяйства: регион, валюта, гектары или сотки, культуры
- Главный экран: сводка по каждой культуре, следующая задача, текущая цена с указанием источника
- Запись за 15 секунд: расход, работа, полив, удобрение, фото, сбор урожая, продажа
- Экран культуры: финансы сезона и история работ
- Цены: рыночная цена и собственные продажи на одном графике, минимум и максимум по годам
- Аналитика: результаты сезона, сравнение культур по прибыли на гектар, вложениям и риску
- Прогноз (ML, следующий этап): диапазоны урожая и прибыли с объяснением

> Цены, погода, история прошлых сезонов и прогноз в прототипе — примерные данные. Записи сохраняются в браузере (localStorage).

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Deploy from branch → `main`).

## Стек

HTML, CSS, JavaScript без сборки и зависимостей. Следующий шаг: React Native + Expo, SQLite для офлайн-данных.
